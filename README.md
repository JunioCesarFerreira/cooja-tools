# Cooja Tools

Tools to facilitate the generation of scripts, execution, and analysis of simulations with Cooja in a Docker container.

## Catalog

- **`docker`**: A guide on how to run Cooja inside a Docker container.
- **`json2cooja`**: A utility that converts a JSON simulation descriptor into the corresponding Cooja simulation files.
- **`edit-positions`**: A web GUI for placing nodes and importing/exporting simulation configuration files in JSON format.
- **`log-analysis`**: Scripts to decode Cooja logs, convert them to CSV, and generate various types of plots.
- **`simulations`**: A directory-based database containing the input and output data of simulations.
